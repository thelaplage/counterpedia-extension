# Counterpedia — Five-Minute Wikipedia Demo

This is the human walkthrough for a Counterpedia Demo Kit. It is also the acceptance script for a clean-Mac certification run.

**First time only:** double-click **Install Counterpedia Demo.command** and let installation finish. For proposal drafting, optionally run **Configure Drafting Key.command**. Normal demos start with **Start Counterpedia Demo.command**.

## 1. Start from the page

Double-click **Start Counterpedia Demo.command**. Use the dedicated demo browser and open a public Wikipedia article. The default walkthrough opens the OpenAI article.

Open the Counterpedia side panel and click **Connect Counterpedia Local** if this browser profile has not paired yet.

**Say:** “Wikipedia is still the place I am reading. Counterpedia is watching the research context beside it.”

## 2. Browse and inspect

Browse normally and inspect the source context and Counterpedia matches shown beside the page.

Do not describe a scanner match as a CHECK result. Browsing and matching are observations about what the browser encountered.

**Say:** “Seeing a source is not the same thing as deciding that a claim is supported.”

## 3. Capture the source

Click **Capture this source**.

Show the retained capture and the visible **UNADMITTED** boundary. Capture means Counterpedia retained evidence and provenance; it does not publish the source, declare it true, or admit it into a governed corpus.

**Say:** “We now have the exact evidence we encountered, but custody is not authority.”

## 4. Optional: draft from retained evidence

If drafting is configured, choose the retained capture as evidence and use **Draft from source**.

Show that the result remains proposal-only.

**Say:** “The agent can work from retained evidence without promoting its own draft into an accepted record.”

## 5. Cross into Counterpedia CHECK deliberately

Choose a concrete claim or question and use **Open in Counterpedia CHECK**.

Pause on the prefilled CHECK view. Opening or prefilling CHECK has not run it.

Then click **Run Check**.

Show the evidence used, what the bounded assessment supports, what is not established, and the resulting receipt / verification material exposed by the current CHECK surface.

**Say:** “CHECK is a separate epistemic act. It only happens when we explicitly run it.”

## 6. Open Counterpedia Terminal

Open the **Counterpedia Terminal** tab and inspect the local record-layer view: retained source custody, provenance, CHECK / receipts, graph or entity context, and the rest of the demo session that the current Terminal exposes.

Do not imply that Terminal gains authority merely by displaying a record.

## 7. Close

**Say:** “The page was where we read. Counterpedia became the record of what we encountered, retained, checked, and can later verify.”

When finished, double-click **Reset Counterpedia Demo.command**. Ordinary reset stops only the demo-owned processes/profile state and does not purge retained Acquisition custody.

## Certification pass

For a clean-Mac recipient certification run, execute this script from the emitted kit itself and require **Check Counterpedia Demo.command** to report ready. A packaging-green build is not recipient-certified until this real recipient journey has run successfully from the artifact being shipped.
